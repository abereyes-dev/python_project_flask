# Flask Portfolio Project

This is a simple portfolio website built with [Flask](https://flask.palletsprojects.com/) as part of my journey into Python and web development.

## Features

- Basic Flask app structure (`app.py`)
- HTML templates using Jinja2 (`templates/base.html`, `templates/index.html`)
- Clean project layout ready to grow into a full portfolio site

## Tech Stack

- Python 3
- Flask
- HTML / Jinja2 templates

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/abereyes-dev/python_project_flask.git
   cd python_project_flask
   ```

2. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install flask
   ```

4. Run the Flask app:

   ```bash
   python app.py
   ```

5. Open your browser and go to:

   ```
   http://127.0.0.1:5000/
   ```
